 Snake Game 

A simple classic **Snake** game built with **Python** and Tkinter
Eat the red food to grow, avoid walls and your own body, and try to beat the High Score


Features

- Start screen** with a **START** button (game does not begin automatically)
- Game Over screen** with **RESTART** button
- High Score counter(kept during the program run)
- Simple grid-based movement
- Basic controls with the arrow keys



Controls

- **Arrow Keys**: Move the snake
  - ↑ Up
  - ↓ Down
  - ← Left
  - → Right
- SPACE: Start / Restart (works when not running)


How to Run

1. Make sure you have **Python 3** installed.
2. Save your game file, for example:
   - `snake_tkinter.py`
3. Run the game:

`bash
python snake_tkinter.py
`

On some systems, you may need:

`bash
python3 snake_tkinter.py
`



Remarks / Notes

- The **High Score resets** when you close the program.
  - If you want, you can extend the game to **save the high score to a file** (like `highscore.txt`).
- You can change the game speed by editing:
DELAY = 120  # lower = faster
